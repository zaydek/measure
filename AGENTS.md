# Agents

This repository is Measure's public face: marketing and the privacy policy. It holds no source
code and ships no package, ever: no zip, no Release. The source, the build, the store listing and its images live in the private
repository.

- Add no source code, source maps or build scripts, no names of private repositories, and
  nothing that pitches another product.
- `README.md` is for people: what Measure does, how to install it, privacy and license.
  Nothing about this repo's internals goes there.
- `media/` holds only the images and GIFs the README shows.
- `gh-pages` holds only the built one-page site (https://zaydek.github.io/measure/), made
  elsewhere and copied in.
- `PRIVACY.md` stays at this exact path: the Chrome Web Store listing links to it.
- Keep `layout .` clean, then commit and push to `main`.
